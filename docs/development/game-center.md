# 每日游戏中心与工作台开关

本文记录每日游戏奖励、管理员工作台开关与导航配置的实现及验证结果。翻译台基础功能见提交 `1725daf10`；本次补充独立功能开关与请求入口。生产部署需单独执行发布流程。

## 当前奖励规则

- 每个账号每天只能开始一局，限时 180 秒，北京时间（UTC+8）00:00 重置。
- 没有拾取绿色 Token：奖励为 0。
- 首个实际拾取的绿色 Token：默认奖励 5 USD 面值额度。
- 后续每个绿色 Token：默认奖励 0.5 USD 面值额度。
- 三个 Token 的奖励为 6 USD；当前生成规则最多产生 187 个掉落，拾取奖励的单局理论上限为 98 USD。
- 按绿色物件数量计奖，普通 Token 的内部数值 10、Boss Token 的内部数值 100 仅用于游戏积分，不作为奖励倍数。
- 服务器确认拾取数量，对局结束后一次性入账。失败或主动结束都结算已拾取奖励；主动结束仍消耗当天机会，且不进入排行榜。
- 已经开始的旧版本对局保留原结算规则，历史积分和已发奖励不重算。

周排行榜沿用现有奖池规则：第 1 / 2 / 3 名分别获得 30% / 20% / 15%，第 4–10 名各 5%，周一 00:05 后结算。

## 管理员入口

1. **系统设置 → 站点与品牌 → 工作台与游戏**，地址 `/system-settings/site/studios-games`：
   - 游戏中心、生图台、翻译台的独立功能开关。
   - 游戏额度奖励开关、首个 Token 金额、后续 Token 金额、每日总预算、每周排行榜奖池。
   - 金额按照站点余额显示单位编辑，复用既有额度换算，不要求管理员填写内部 quota 数字。
2. **系统设置 → 站点与品牌 → 顶部导航**：游戏中心的顶部入口显示开关。
3. **系统设置 → 站点与品牌 → 侧边栏模块**：生图台、翻译台、游戏中心分别显示或隐藏，不再共用游乐场键。

功能开关与显示开关独立：隐藏入口仍可通过地址访问；停用工作台会同时阻止页面进入和对应工作台请求。游戏中心停用后阻止新对局，已开始的对局仍可续玩、刷新恢复和结算。管理员设置接口在功能关闭后仍然可用。

个人侧边栏偏好也补充上述三个入口；个人配置只能进一步隐藏管理员允许显示的内容。搜索菜单采用同样的可见性过滤。

## 预算与持久化

- 默认奖励关闭；配置中的默认金额为首个 5 USD、后续 0.5 USD。
- 每日总预算为 0 表示不设置总额上限。金额与预算在周期首次开局时保存快照，开始后的修改在下一周期生效。
- 有预算上限时，开局先预留按当前规则可能得到的最高奖励。预算不足时不开局、不消耗当天次数；结算后释放未使用的预留额度。
- 游戏金额和三项功能开关通过一个管理员请求、同一个数据库事务保存；公共状态在保存后刷新。
- `game_runs` 的 `(user_id, day)` 唯一约束限制每日次数；`game_rewards` 的唯一流水与钱包更新在同一事务，重复请求不重复入账。
- 新对局使用奖励版本 2，记录首个和后续奖励快照及预留额度；旧对局继续原固定奖励方式。
- 每分钟完成过期对局并释放预算；使用原额度缓存同步方法和金额日志格式。

## 接口与模拟

- 游戏 API 只允许网页登录会话，拒绝个人访问令牌。修改配置额外要求 Root 权限。
- 生图工作台继续使用 `/pg/image-studio`，在转发前检查功能开关。
- 翻译台使用独立 `/pg/translation-studio`，通过开关后复用原游乐场的模型选择、分组校验、转发及扣费流程。
- 工作台开关仅控制工作台入口和对应请求，不影响用户正常使用 `/v1` API。
- 游戏采用 Go 权威模拟与 TypeScript 本地预测，100ms 固定步长，每两秒提交一次操作；计分与奖励不接受客户端直接上报。
- 关闭或刷新不会暂停计时。超过五秒的操作空档按无操作推进，奖励展示采用服务器已确认的拾取数。

## 2026-10-18 验证记录

- SQLite 3.50.4、MySQL 8.4.11、PostgreSQL 17.10 的真实实例验证通过。
- `go test ./model -run '^TestGame' -count=1 -v` 覆盖新库、旧游戏表升级、重复迁移、历史奖励保留、每日唯一场次、并发预算预留、预算不足回滚、不重复发奖、零拾取、Boss 按一个物件计数及最大 98 USD 的边界。
- `go test ./router ./middleware -count=1` 通过，包含工作台独立关闭、关闭请求不转发不扣费、翻译新接口保持原扣费链路、访问令牌限制和路由登记。
- 48 项前端测试通过，覆盖跨语言游戏回放、翻译台回归、三个入口的独立显示与功能开关。
- 前端修改文件 lint、类型检查、生产构建和 Go 构建通过。
- 浏览器实测：拾取 3 个 Token，入账 3,000,000 quota（6 USD），账户余额准确增加；重复结束请求不多发，重复开始仍返回同一局。零拾取账号入账为 0。
- 浏览器验证三项功能开关保存、刷新后保留；停用工作台返回 403 且额度不变；隐藏侧边栏仍能按地址访问；顶部和侧边栏显示互不影响。
- 管理员关闭游戏后，已有普通用户对局仍能刷新续玩并正确结算；普通用户不能修改管理员设置。
- 新管理员页面完成七种语言、320 / 390 / 1440px 共 21 组视口验证，未出现页面脚本错误和横向溢出。
- 本地自动化测试采用正常页面导航；大量连续冷启动会触发原有每 20 分钟 20 次的认证限流，不修改生产限流配置。
